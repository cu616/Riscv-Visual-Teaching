# K-Star 开鸿生态卓越激励计划申报材料

本目录用于整理“电芯学生队”参加 K-Star 开鸿生态卓越激励计划的申报底稿和交接资料。原有比赛提交文件、获奖通知和工程文档继续保留在原目录中，本目录只放经过筛选的申报文本及证据索引，不存放身份证、银行卡、签字协议等个人敏感资料。

## 当前申报定位

- 拟申报奖项：新锐
- 拟申报身份：高校学生
- 项目名称：基于 OpenHarmony 与 RISC-V 的指令集实体化教学智能玩具
- 团队名称：电芯学生队
- 核心成果：RISC-V 指令集可视化教学软件、OpenHarmony 适配工程、香橙派 RV2 平台适配材料、源码复现文档
- 外部认可：2025 年深圳开源鸿蒙/RISC-V 创新应用大赛优秀团队奖
- 完整项目仓库：https://github.com/cu616/Riscv-Visual-Teaching
- AtomGit 公开仓库：https://atomgit.com/txydc/openharmony-riscv-teaching
- OR 大赛代码仓库：https://atomgit.com/szor/dianxinxuesheng
- 比赛官方报道：https://mp.weixin.qq.com/s/zslC6pFXVnATT-EBp2LmTg
- 比赛相关报道：https://mp.weixin.qq.com/s/JOcZAXCfUwtI4Yw0NJNDxQ

## 使用顺序

1. 先完成 `00_事实核对与填写说明.md` 中剩余的确认项。
2. 补齐真机证据的文件名或公开链接。
3. 将技术博客和代码仓库发布为无需登录即可访问的链接。
4. 从证据索引中选出最有说服力的五项成果，填入申报表。
5. 由申报人、原项目负责人和指导老师共同核对一次成员贡献与成果归属。

## 材料边界

本项目已经完成软件原型、OpenHarmony 适配工程和香橙派 RV2 真机运行，并留有证据。团队没有修改香橙派 RV2 硬件，因此申报材料统一把开发板称为运行与验证平台，不写成团队自主研发的硬件。
