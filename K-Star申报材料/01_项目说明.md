# 项目说明

## 项目名称

基于 OpenHarmony 与 RISC-V 的指令集实体化教学智能玩具

## 项目简介

RISC-V 汇编入门常常从指令格式和寄存器规则开始。对初学者来说，`rd`、`rs1`、`rs2` 和立即数只是纸面符号，一条指令执行后为什么改变某个寄存器、内存地址或 PC，也很难直接观察。

本项目围绕这一教学问题开发了 RISC-V 指令集可视化教学软件。学习者可以使用指令积木和操作数积木构造程序，系统同步生成汇编文本，并通过单步执行展示寄存器、内存和 PC 的变化。项目希望把“阅读汇编”变成“拼接、执行和观察”，帮助初学者建立指令格式与机器状态之间的联系。

项目目前形成了 Windows/Web 演示版本和 OpenHarmony 适配工程。OpenHarmony 版本采用 ArkTS 外壳与 ArkWeb 承载本地教学页面，在保留既有交互逻辑的同时，对触控拖拽、页面尺寸和本地资源加载进行了适配。团队完成了该版本在香橙派 RV2 上的真机运行，并配套整理了源码复现包、移植记录和 HDC 部署检查清单。

## 已完成内容

### 教学软件

- 使用指令积木和操作数积木构造 RISC-V 教学程序。
- 生成结构化指令与汇编预览。
- 支持单步执行和连续运行。
- 展示 PC、寄存器和内存状态变化。
- 支持十进制、十六进制和二进制观察。
- 覆盖常用算术、逻辑、移位、访存、分支和跳转指令。

### OpenHarmony 适配

- 建立 Stage 模型 OpenHarmony 工程。
- 使用 ArkTS 页面加载 rawfile 中的本地 Web 资源。
- 针对 ArkWeb 环境调整拖拽和触控交互。
- 面向 1920×1080 教学屏调整工作台布局。
- 预留运行环境识别、案例保存和导入接口。
- 提供同步脚本、结构烟测和部署排查文档。

### 比赛与传播

项目参加了 2025 年深圳开源鸿蒙/RISC-V 创新应用大赛。团队围绕教学痛点、软件实现、OpenHarmony 适配路线和后续实体积木设想进行了现场展示，并获得优秀团队奖。现有材料包括答辩PPT、产品研发设计报告、源码复现包、现场照片和公众号推文草稿。

## 对开源鸿蒙生态的价值

本项目的贡献方向是教育应用和开发经验沉淀。它提供了一个可演示的 OpenHarmony 教学应用样例，也记录了 Web 教学软件迁移到 ArkWeb 本地资源工程时遇到的工程问题。代码、移植记录和部署检查清单经过整理后，可以供高校学生、教学团队和首次接触 OpenHarmony 开发板的开发者参考。

项目后续仍需补充真实使用数据和持续社区维护记录。K-Star 申报阶段应优先公开技术博客、完整代码仓库和可复现文档，让评委能够直接查看并验证成果。OR 大赛代码仓库和两篇比赛报道可以补充证明项目的参赛过程与外部认可。
