# RISC-V 指令集可视化教学软件 MVP

这是第一版无依赖静态 MVP，用来验证产品核心闭环：

```text
指令积木编辑
→ 结构化指令
→ 汇编预览
→ 教学模拟执行
→ 寄存器 / 内存 / PC 状态变化
→ 数据流动画
→ 教学解释与错误提示
```

## 当前功能

- 支持 `add`、`sub`、`addi`、`lw`、`sw`、`beq`
- 支持寄存器 `x0` 到 `x31`
- `x0` 恒为 0
- 支持把指令大积木拖到编辑区，再把寄存器 / 立即数 / 标签小积木拼接到接口
- 支持立即数槽位键盘输入
- 支持把命名标签贴到任意指令上，并由 `beq` 引用
- 支持内存读写示例
- 支持单步执行、自动执行、暂停、重置
- 支持汇编文本和结构化 JSON 预览
- 支持执行日志与中文教学解释
- 支持独立 CPU 数据通路舞台，分步展示取指、读寄存器、ALU、访存、写回、PC 更新
- 支持预置案例
- 支持 OpenHarmony 概念展示页

## 当前交互方式

1. 从左侧拖动 `add`、`addi`、`lw` 等指令大积木到编辑区画布。
2. 指令大积木可以在画布中自由拖动；程序执行顺序按积木的垂直位置从上到下解析。
3. 可拖动素材区和编辑区之间的竖向分隔条，调整各区域宽度。
4. 从左侧生成一个寄存器、立即数或标签小积木，再拖到指令下方对应接口。
5. 指令积木外观为上方一条长方形大积木，下方拼接多个小长方形操作数积木。
6. 小积木不是嵌入表单，而是作为独立矩形贴在指令积木下方，形成上下相邻的拼接效果。
7. 立即数可以在左侧输入生成，也可以在指令的立即数小块里直接键盘输入。
8. 把浅绿色标签小积木贴到某条指令顶部的“标签帽”上，表示该指令拥有这个标签。
9. 对 `beq` 指令，把同名绿色标签小积木拖到 `label` 接口，表示分支目标。

## 运行方式

在仓库根目录执行：

```powershell
node .\app\server.mjs
```

然后打开：

```text
http://localhost:4173
```

也可以直接用浏览器打开：

```text
app/index.html
```

## 后续迁移方向

当前版本故意不依赖 npm 包，方便快速演示和验收。后续正式工程可以迁移为：

- Electron
- React + TypeScript
- Vite
- Blockly

迁移时优先保留：

- `src/instructions.js` 中的指令定义、解析和汇编格式化思路
- `src/simulator.js` 中的教学模拟器状态设计
- `src/app.js` 中的单步执行、日志、案例和状态联动流程
