# 项目进度与结构总结

更新时间：2026-05-01

## 1. 当前项目定位

本仓库已经从单纯的 Codex 学习资料库，推进为《基于 RISC-V 指令集可视化教学的桌面软件》的原型开发仓库。

当前软件目标是：用接近真实积木拼接的方式构造 RISC-V 教学指令，并通过可视化数据流帮助初学者理解寄存器、ALU、内存、PC 与指令执行过程之间的关系。

### 2.2 软件 MVP

已在 `app/` 中实现无依赖 Web MVP，当前版本为 `v0.3.0`，可以通过本地静态服务器运行。

当前支持：

- 指令大积木拖拽到编辑区。
- 指令积木可在画布中自由移动。
- 程序执行顺序按指令积木在画布中的高度从上到下解析。
- 操作数小积木：
  - 寄存器
  - 立即数
  - 标签
- 支持标签贴到指令顶部，并被 `beq` 引用。
- 支持 `add`、`sub`、`addi`、`lw`、`sw`、`beq`。
- v0.3 已扩展常用教学指令：
  - 逻辑：`and`、`or`、`xor`、`andi`、`ori`、`xori`
  - 移位：`sll`、`srl`、`sra`、`slli`、`srli`、`srai`
  - 分支：`bne`、`blt`、`bge`、`bltu`、`bgeu`
  - 跳转：`jal`、`jalr`
  - 教学伪指令：`j`、`bltz`
- 支持寄存器、内存、PC 状态显示。
- 支持独立数据流可视化舞台。
- 支持执行日志与教学解释。
- 支持示例案例加载。
- 支持一键启动脚本。
- v0.2 已增加演示模式、排序辅助线、指令拖动网格吸附、拖拽时显示空接口提示。
- v0.3 已增强逻辑、移位、分支、跳转的数据流动画阶段文案。
- v0.3 已补充核心测试，覆盖新增指令、`x0` 恒零、按画布高度排序、标签跳转和 `shamt` 范围校验。

## 5. 已知问题与下一阶段重点

当前版本仍是无依赖 Web MVP，还不是真正的 Blockly / Electron 工程。

下一阶段详细计划见：[下一阶段版本计划](下一阶段版本计划.md)。

v0.2 已完成其中一部分可落地内容：

- 机器状态与数据流保持右侧同列显示。
- 指令积木主体与下方操作数视觉进一步分离。
- 空接口默认弱化，仅在拖动操作数时显现。
- 指令块拖动后按网格吸附。
- 拖动时显示排序辅助线。
- 增加演示模式。

下一阶段建议优先处理：

1. 继续打磨真实积木拼接体验：
   - 小积木自由拖动
   - 靠近指令下边缘时自动吸附
   - 未吸附时保留在画布中
2. 进一步压缩指令积木视觉，减少 UI 容器感。
3. 继续改进数据流动画，使其更像教学演示，而不是简单高亮。
4. 将当前原型迁移到正式工程：
   - Electron
   - React
   - TypeScript
   - Vite
   - Blockly
5. 增加浏览器端 UI 自动化验收。
6. 继续增加更多指令测试用例。

## 6. v0.3 指令扩展来源与约束

本轮扩展以 RISC-V 官方 Unprivileged ISA 文档为优先参考：

- `https://docs.riscv.org/reference/isa/unpriv/rv32.html`
- `https://docs.riscv.org/reference/isa/v20240411/unpriv/rv32.html`
- `https://docs.riscv.org/reference/isa/v20240411/_attachments/riscv-unprivileged.pdf`

关键约束：

- `lw` 必须保持 `lw rd, imm(rs1)`，可视化顺序为 `rd`、`imm`、`rs1`。
- `sw` 必须保持 `sw rs2, imm(rs1)`，可视化顺序为 `rs2`、`imm`、`rs1`。
- `jal` 使用 `jal rd, label`。
- `jalr` 使用 `jalr rd, imm(rs1)`。
- 标准 RV32I 中变量移位使用 `sll/srl/sra rd, rs1, rs2`，不使用 MIPS 风格的 `sllv` 指令名。
- `bltz` 不是 RV32I 基础独立指令，本项目仅作为教学伪指令展示，等价于 `blt rs1, x0, label`。
