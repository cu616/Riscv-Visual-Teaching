# 项目进度与结构总结

更新时间：2026-05-03

## 0. 2026-05-03 技术路线调整

当前项目路线已经重新收束：

```text
主线：非 Blockly 自研积木桌面版
保留：Blockly 迁移版作为技术验证
远期：OpenHarmony 采用 ArkWeb/WebView 先承载，再逐步原生化
```

原因是本项目最终要表达的是 RISC-V 指令字段像真实积木一样上下贴边拼接：上层是指令长条，下层是寄存器、立即数、地址、标签等小长方体。Blockly 默认更适合右侧拼图和内嵌输入，虽然可以自定义方形卡口，但很难自然达到当前产品要求的上下两排长方体贴边效果。

因此，后续正式产品优先回到 `app/` 的自研积木原型，并将其桌面化；`desktop/` 的 Blockly + Electron 工程保留为技术验证，用于参考 TypeScript 化、保存加载、Electron 打包和工作区序列化经验。

详细说明见：`docs/技术路线决策与阶段复盘.md`。

## 1. 当前项目定位

本仓库已经从单纯的 Codex 学习资料库，推进为《基于 RISC-V 指令集可视化教学的桌面软件》的原型开发仓库。

当前软件目标是：用接近真实积木拼接的方式构造 RISC-V 教学指令，并通过可视化数据流帮助初学者理解寄存器、ALU、内存、PC 与指令执行过程之间的关系。

### 5.4 迁移版基本使用流程

1. 从左侧 Blockly 工具箱选择指令类别，例如算术、逻辑、访存、分支、跳转。
2. 拖出一条指令积木到工作区。
3. 从“操作数”分类拖出寄存器、立即数、移位量或标签引用小积木。
4. 将操作数小积木连接到指令积木对应输入位置。
5. 需要标签时，拖出绿色标签帽并连接到目标指令左侧。
6. 查看下方汇编预览，确认 Blockly 已转换为结构化指令。
7. 点击“单步执行”观察 PC、寄存器、内存和数据流说明变化。
8. 点击“运行到结束”快速演示完整程序效果。
9. 在机器状态区点击目标寄存器或内存单元，可查看详情并写入初始化值。
10. 使用 DEC / HEX / BIN 切换机器状态显示进制。
11. 点击“保存案例”导出 `.riscvteach.json`。
12. 点击“导入案例”恢复保存的 Blockly 工作区。

## 7. v0.3 指令扩展来源与约束

本轮扩展以 RISC-V 官方 Unprivileged ISA 文档为优先参考：

- `https://docs.riscv.org/reference/isa/unpriv/rv32.html`
- `https://docs.riscv.org/reference/isa/v20240411/unpriv/rv32.html`
- `https://docs.riscv.org/reference/isa/v20240411/_attachments/riscv-unprivileged.pdf`

关键约束：

- `lw` 必须保持 `lw rd, imm(rs1)`，可视化顺序为 `rd`、`imm`、`rs1`。
- `sw` 必须保持 `sw rs2, imm(rs1)`，可视化顺序为 `rs2`、`imm`、`rs1`。
- `jal` 使用 `jal rd, label`。
- `jalr` 使用 `jalr rd, imm(rs1)`。
- 标准 RV32I 中变量移位使用 `sll/srl/sra rd, rs1, rs2`，不使用 MIPS 风格的 `sllv` 指令名。
- `bltz` 不是 RV32I 基础独立指令，本项目仅作为教学伪指令展示，等价于 `blt rs1, x0, label`。
