# 明早验收与问题定位清单

日期：2026-05-04 / 2026-05-05 交接

## 1. 最快验收路径

请按顺序做，最快能发现问题：

1. 双击根目录：

```text
打开非Blockly自研积木桌面版.bat
```

2. 确认打开的是独立应用窗口模式。
3. 点击“单步执行”，确认默认程序还能执行。
4. 拖一个 `addi` 指令到画布。
5. 从左侧拖 `x1` 到画布空白处，确认出现自由小积木。
6. 把自由 `x1` 拖近 `rd` 槽，确认槽位会高亮并自动吸附。
7. 从 `rd` 槽把 `x1` 拖出到画布空白处，确认 `rd` 变空并出现自由小积木。
8. 拖一个立即数到 `imm` 槽，双击该立即数小积木，确认出现页面内小浮层并可以修改整数。
9. 在右侧“机器状态初始化”中写入 `x1 = 16`，确认寄存器格子出现初始值标记。
10. 切换到内存，写入 `16 = 99`，确认内存格子出现初始值标记。
11. 在“教学备注”中输入一段文字。
12. 点击“保存案例”，保存 `.riscvteach.json`。
13. 点击“清空程序”。
14. 点击“导入案例”，确认指令、自由小积木、初始状态和教学备注恢复。
15. 连续点击“下一步”，确认当前执行的指令积木边缘高亮。
16. 点击“上一步”，确认 PC、寄存器、内存和执行日志回到上一步。
17. 点击“自动执行”，确认执行进度会变化，且运行中编辑区不会被误操作。
18. 拖动一条指令到两条指令之间，确认插入提示显示“第 N 步”，松手后主列能整理成上下步骤栈。
19. 填写案例标题、教学目标、讲解步骤，保存导入后确认三段内容恢复。
20. 拖出自由小积木，确认右下角出现删除区，拖进去后小积木删除。
21. 右键自由小积木选中；按 Ctrl 右键多个小积木；按 Delete 或 Backspace 删除选中项。
22. 普通上下拖动一条指令，确认它不会被强制吸回固定位置。
23. 把两条指令积木明显重叠，松手后确认系统自动整理为紧密贴合布局，读取顺序为从上到下、同层从左到右。
24. 单步执行时，确认高亮框紧贴指令头本体，而不是包住大块空白区域。

## 2. 反馈时请优先说明

如果有问题，请尽量按这个格式反馈：

```text
问题类型：
复现步骤：
看到的现象：
期望效果：
是否每次都出现：
```

示例：

```text
问题类型：自由小积木吸附
复现步骤：拖 x1 靠近 addi 的 rd 槽
看到的现象：距离很远就吸附
期望效果：更靠近槽位才吸附
是否每次都出现：是
```

## 4. 当前已知风险

- 自由小积木吸附阈值是第一版，可能需要按手感调整。
- 立即数双击编辑已改为页面内浮层，但位置和手感仍需要人工确认。
- 初始状态标记和备注输入区需要人工确认是否适合课堂演示。
- “上一步”是执行状态回退，不会撤销积木编辑、拖拽或保存导入操作。
- Electron 原生 exe 还没有修完，当前稳定打开方式是 Edge / Chrome 应用窗口模式。
- `app/src/app.js` 仍包含拖拽和吸附核心逻辑，后续还要继续拆分。
