### 3.9 指令类型扩展

完成状态：已完成首轮扩展。

目标：在当前教学模拟器基础上扩展常用指令，使演示内容更丰富。

重要要求：

- 扩展前必须查询官方或可靠资料。
- 不凭记忆添加指令。
- 严格检查字段顺序、汇编格式、语义。
- 避免再次出现 `lw rd, imm(rs1)` 的可视化顺序错误。

优先参考资料：

- RISC-V 官方 Unprivileged ISA 文档：`https://docs.riscv.org/reference/isa/unpriv/rv32.html`
- RISC-V 官方 2024-04-11 RV32I 文档：`https://docs.riscv.org/reference/isa/v20240411/unpriv/rv32.html`
- RISC-V Unprivileged ISA PDF：`https://docs.riscv.org/reference/isa/v20240411/_attachments/riscv-unprivileged.pdf`

本轮已完成的扩展指令：

#### A. 逻辑运算 R 型

- `and rd, rs1, rs2`
- `or rd, rs1, rs2`
- `xor rd, rs1, rs2`

字段顺序：

```text
rd, rs1, rs2
```

教学重点：

- 位运算。
- 适合配合二进制显示讲解。

#### B. 移位 R 型

- `sll rd, rs1, rs2`
- `srl rd, rs1, rs2`
- `sra rd, rs1, rs2`

注意：

- 标准 RV32I 中是 `sll/srl/sra`，不是 MIPS 风格的 `sllv`。
- `sllv` 不是标准 RISC-V RV32I 指令名；如需讲“变量移位”，用 `sll rd, rs1, rs2` 表达。

字段顺序：

```text
rd, rs1, rs2
```

教学重点：

- `rs2` 的低 5 位作为移位量。
- 左移、逻辑右移、算术右移的区别。

#### C. 移位 I 型

- `slli rd, rs1, shamt`
- `srli rd, rs1, shamt`
- `srai rd, rs1, shamt`

字段顺序：

```text
rd, rs1, shamt
```

教学重点：

- 立即数移位量。
- RV32 中移位量通常取 5 位。

#### D. 逻辑立即数 I 型

- `andi rd, rs1, imm`
- `ori rd, rs1, imm`
- `xori rd, rs1, imm`

字段顺序：

```text
rd, rs1, imm
```

教学重点：

- 掩码。
- 位设置、位清除、位翻转。

#### E. 条件分支 B 型

标准 RV32I 条件分支：

- `beq rs1, rs2, label`
- `bne rs1, rs2, label`
- `blt rs1, rs2, label`
- `bge rs1, rs2, label`
- `bltu rs1, rs2, label`
- `bgeu rs1, rs2, label`

字段顺序：

```text
rs1, rs2, label
```

关于 `bltz`：

- `bltz` 是常见伪指令风格，不是 RV32I 基础指令的标准独立指令。
- 在 RISC-V 中可表示为：

```text
blt rs1, x0, label
```

如果加入 `bltz`，应标记为“教学伪指令”，内部转换为 `blt rs1, x0, label`。

#### F. 无条件跳转

标准指令：

- `jal rd, label`
- `jalr rd, imm(rs1)`

字段顺序：

```text
jal rd, label
jalr rd, imm(rs1)
```

教学重点：

- `jal` 是 J 型。
- `jal` 会把下一条指令地址写入 `rd`。
- 如果不需要保存返回地址，可用 `rd=x0`，相当于无条件跳转伪指令 `j label`。

实际执行结果：

1. 已实现 `and/or/xor`、`sll/srl/sra`、`andi/ori/xori`。
2. 已实现 `bne/blt/bge/bltu/bgeu`。
3. 已实现 `jal/jalr`。
4. 已实现 `slli/srli/srai`。
5. 已加入 `j/bltz`，并在文档中标注为教学伪指令。

### 3.10 数据流动画方案优化

如果指令扩展后仍有时间，继续优化数据流动画。

初步方案：

1. 按指令类别选择动画路径：
   - 算术 / 逻辑：寄存器 → ALU → 写回
   - 立即数：寄存器 + 立即数 → ALU → 写回
   - 访存：寄存器 + 偏移 → 地址计算 → 内存 → 写回 / 写入
   - 分支：寄存器比较 → 分支判断 → PC 更新
   - 跳转：PC + offset → 目标地址，同时 rd 接收返回地址
2. 每个阶段同步一句教学解释。
3. 对逻辑运算突出“按位”概念。
4. 对移位指令突出“位向左/右移动”的视觉。
5. 对跳转突出 PC 改变，而不是寄存器值变化。

今晚不做复杂 SVG 重画，优先在现有数据流舞台上增强节点文案和阶段脚本。
