# 夜间自动化推进计划

## 1. 今晚目标

用户睡觉后进入无人值守开发。当前没有新的理论问题需要睡前确认，默认继续执行已确认路线：


## 2. 自动化执行边界

允许自动完成：

- 修改 `app/` 主线代码。
- 小步拆分 `app/src/app.js`。
- 增加主线保存 / 导入能力。
- 增加自由小积木与自动吸附的第一版交互。
- 更新文档与明早检查清单。
- 运行 `npm.cmd run check` 和 `npm.cmd test`。

不自动完成：

- 不引入新依赖。
- 不迁移到 Blockly。
- 不重写成 React / TypeScript。
- 不删除现有 Blockly 验证工程。
- 不做完整 Electron exe 打包，除非已有命令稳定通过。

## 3. 今晚任务清单

### 3.1 启动链路

当前一键入口：

```text
打开非Blockly自研积木桌面版.bat
```

它调用：

```text
scripts/launch_non_blockly_app.ps1
```

行为：

- 检查 `http://localhost:4173` 是否可访问。
- 未启动时自动运行 `npm.cmd start`。
- 优先用 Edge / Chrome 的 `--app=http://localhost:4173` 应用窗口模式打开。
- 日志写入 `logs/launch_non_blockly_app.log`。

明早如果打不开，优先查看：

```text
logs/launch_non_blockly_app.log
```

### 3.2 模块拆分

目标：降低 `app/src/app.js` 复杂度。

已拆分：

- `app/src/datapath.js`：数据流动画步骤和节点文案。
- `app/src/ui-utils.js`：拖拽 payload、网格吸附、显示进制格式化、操作数显示等工具函数。

明早如果数据流动画异常，优先查：

```text
app/src/datapath.js
```

如果拖拽 payload、进制显示、操作数文字异常，优先查：

```text
app/src/ui-utils.js
```

### 3.3 保存与导入

目标：让非 Blockly 主线可以保存和恢复当前案例。

工具栏新增：

- `保存案例`
- `导入案例`

保存文件后缀：

```text
.riscvteach.json
```

保存内容包括：

- `instructions`
- `looseOperands`
- `displayBase`
- `initialState`
- `notes`
- `source`

明早验收：

1. 打开应用。
2. 拖动或修改几条指令。
3. 点击“保存案例”。
4. 清空程序。
5. 点击“导入案例”。
6. 确认布局和指令恢复。

### 3.4 自由小积木与吸附

目标：开始从“槽位表单模拟”走向“真实积木吸附关系”。

第一版行为：

- 从左侧素材区拖出寄存器 / 立即数 / 标签。
- 如果直接拖到画布空白处，会生成自由漂浮的小积木。
- 自由小积木可以在画布中移动。
- 自由小积木靠近匹配槽位时会高亮目标并自动吸附。
- 已吸附的寄存器 / 立即数 / 标签小积木可以再次拖出。
- 已吸附的立即数小积木可双击编辑整数值。
- 自由小积木双击可删除。
- 保存文件会记录自由小积木。

明早重点验收：

1. 拖一个 `addi` 指令到画布。
2. 从左侧拖 `x1` 到画布空白处，确认它停留为自由小积木。
3. 把自由 `x1` 靠近 `rd` 槽位，确认能吸附。
4. 把已吸附的 `x1` 拖出到画布空白处，确认字段变空且小积木保留。
5. 把立即数小积木吸附到 `imm` 槽，双击它改值，确认汇编预览同步变化。
6. 拖错类型，例如把标签拖到寄存器槽，确认不会吸附。
7. 保存并导入，确认自由小积木仍在。

如果这块出问题，优先查：

```text
app/src/app.js
```

重点函数：

- `addLooseOperand`
- `renderLooseOperands`
- `bindLooseOperandDrag`
- `findNearestAttachTarget`
- `attachLooseOperand`
- `detachPayloadSource`

### 3.5 保存格式模块

目标：避免保存/导入逻辑散落在 UI 主文件中。

新增：

```text
app/src/case-format.js
```

职责：

- 生成 `.riscvteach.json` 保存对象。
- 解析导入文件。
- 保留 `instructions`、`looseOperands`、`displayBase`。

明早如果保存文件内容异常，优先查这个文件。

## 4. 明早快速审阅顺序

建议按这个顺序看，最快发现问题：

1. 双击 `打开非Blockly自研积木桌面版.bat`。
2. 确认打开的是应用窗口模式，不是普通标签页。
3. 加载“立即数赋值”或默认程序，点“单步执行”。
4. 测试保存 / 导入。
5. 测试自由小积木：
   - 拖到空白处。
   - 拖向槽位吸附。
   - 从槽位拖出。
   - 双击删除自由小积木。
6. 看右侧机器状态和数据流动画是否还正常。
7. 如果发现问题，反馈时优先说明：
   - 哪一步出问题。
   - 是保存导入、自由小积木、吸附、执行、还是动画。
   - 是否能复现。

## 6. 剩余风险

- 自由小积木吸附是第一版，吸附阈值和手感可能还要明早按视觉反馈调。
- 立即数槽位已改成小积木形态并支持双击编辑，但输入体验还可以继续打磨，例如改成轻量浮层而不是浏览器 prompt。
- Electron 原生窗口仍未修完，当前稳定入口是 Edge / Chrome 应用窗口模式。
- `app/src/app.js` 已拆出部分模块，但拖拽和吸附核心仍在该文件内，后续还需要继续拆分。
